# Eason Fast Delivery Food

Minecraft Java 26.3 + Fabric mod for HMCL.

## 功能

- 鸡蛋放进熔炉可以烧成水煮蛋。
- 水煮蛋可以食用，恢复 4 点饥饿值。
- 铁粒放进熔炉可以烧成钱。
- 铁锭 + 红石可以合成疾速外卖手机。
- 使用疾速外卖手机会消耗 2 到 3 个钱。
- 外卖史蒂夫会从远处过来送食物，60 秒没到会传送送达。

## 打包

这个项目需要 Java 25、Minecraft 26.3、Fabric Loader 0.19.5。

```sh
gradle build
```

打包完成后，把这个文件放进 HMCL 的 `26.3-Fabric` 实例 `mods` 文件夹：

```text
build/libs/eason-delivery-fast-mod-1.0.7.jar
```

如果你的 HMCL 实例没有 Fabric Loader，请先在 HMCL 里给该实例安装 Fabric。
